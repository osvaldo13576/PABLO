# PABLO

Sistema automatizado para la medición y adquisición de potencia en antenas de radiofrecuencia (RF), orientado a aplicaciones en Imagen por Resonancia Magnética (IRM).

## Descripción del Proyecto

**PABLO** es un proyecto enfocado en el desarrollo y control de un sistema electromecánico y de adquisición de datos para caracterizar y mapear la distribución de potencia en antenas de radiofrecuencia (RF).

### Características Principales

- **Control de Movimiento Automatizado:** Secuencia de desplazamiento bidimensional impulsada por dos motores a pasos y delimitada por cuatro interruptores de fin de carrera, asegurando recorridos precisos y repetibles.
- **Adquisición y Estructuración de Datos:** Generación de vectores de muestreo para la construcción estructurada de matrices donde se almacenan los niveles de potencia adquiridos en cada coordenada.
- **Rutina de Retorno Seguro:** Algoritmo de restablecimiento que posiciona el sistema nuevamente en el punto de origen una vez completada la captura de información.
